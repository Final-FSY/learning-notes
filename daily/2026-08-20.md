## 学到的知识

- **userdebug 固件**：`adb root` 可用，方便调试；代价是更开放的权限面。
- **小内存设备的安装技巧**：GUI 应用商店安装会因内存不足卡死，命令行 `adb install` 不经过应用商店的界面层，资源占用小得多。
- **evdev 输入设备写入**：往 `/dev/input/eventN` 写事件要严格按 input_event 结构体格式（24 字节），且要写对设备——sendevent 有效，说明格式对、设备对。
- **sunxi-ir-uinput 的特殊性**：这款红外设备（/dev/input/event1）吃的是 **Android keycode**，不是 Linux keycode，模拟按键时必须转换。
- **mksh 的 echo 是内建命令**：没有 fork 子进程的开销，比 toybox printf 更快——在循环里高频调用时差异明显。
- **架构设计思路**：HTTP 服务端把按键请求转成 adb shell 管道里的指令，电视端用 FIFO + 常驻 C 程序写 input 设备——把「网络请求」翻译成「内核输入事件」，这是自制遥控器的核心思路。

## 踩坑记录

- **evdev 直写失败**：`printf`/`dd`/`cat` 直写 24B/96B 全部无效——96B 报 EINVAL（一次只收 24B）；24B 的 printf/dd/cat 写进去 getevent 也看不到（原因未明）。最终用 C 程序 `open + write`（与 sendevent 同行为）解决。
- **pkill -f 自杀坑又踩 2 次**：`pkill -f` 会匹配到自己的命令行，把自己杀了。用 `pkill -f` 前先确认模式不会命中自身，或改用精确进程名。
- **当贝市场内安装卡死**：1.5G 内存跑不动应用商店的安装流程，换 adb 直接装。
- **彩色条纹虚惊**：开机画面花屏 ≠ 系统坏了，先等系统起来再判断。
