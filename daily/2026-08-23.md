## 今天干了什么

1. **修复表情扫雷加载不出来**：根因有两个——① `index.html` 文件被截断，只剩 head+CSS（267 行），整个 `<body>` 丢失；② 表情图依赖 `twemoji.maxcdn.com`（国内被墙）。从上游仓库恢复 body 后，把 29 个表情 PNG 本地化，twemoji.js 的 base 改为本地 `./emoji/`，还去掉了 Google Analytics / Google Fonts 等被墙外链。

5. **五子棋页面重构**：删掉段位系统/规则/版本记录，排版改成两列 + 全宽状态栏，页面从 2545px 瘦到 1074px。
6. **全站内容逐字核查**：按皮皮要求核查 16 个页面，揪出一批错误——AdGuard 页写了"全屋生效中"但实际早关了、InfoScreen 说"另一台 Orange Pi 跑服务"但已挪到树莓派、一堆游戏攻略描述与实际不符（键位、作者、颜色、位置全查了一遍）。
7. **真机验证抓出 3 个真 bug**：字体图标 404（fontawesome 的 `../webfonts/` 路径放错）、hextris 还挂着已死的 AdSense/域名、扫雷数字表情 404（twemoji 文件名不补前导零）。
8. **糖果盒默认中文**：把 `gameLanguage` 默认值改成 `"zh"`，并加内联脚本强制旧存档（`localStorage` 里存了 `en`）转中文。

12. **服务器响应头 bug 修复**：加 `Cache-Control: no-cache` 时顺序放错导致整个网站短暂打不开，override `send_response()` 后修复。

## 学到的知识

- **CDN 被墙的通用排查思路**：网页加载慢/白屏，先看控制台 Network 里哪个请求 pending/failed，域名是国外的（maxcdn、Google、cdnjs、imgur）大概率是墙的锅。解法就一个：**下载到本地，改路径**。
- **twemoji 文件名规则**：码点转文件名时不补前导零——`31-20e3.png` 而不是 `0031-20e3.png`。下载文件命名要以游戏实际请求为准，别靠推测。
- **iframe 透明背景透传**：页面 body 背景透明时，透出的是 iframe 元素的背景色，不是父页面 body 的。设置 iframe 的 `background:#fff` 即可。
- **gzip 压缩实现**：仅对 `Accept-Encoding: gzip` 的客户端压缩，且文件 >200B 才压，避免小文件白费 CPU。
- **进度条实现**：清单文件（manifest.json）列出资源字节数，页面用 Performance API 统计真实下载量，loaded/total 算百分比。这是"看起来真实"的进度条做法。
- **HTTP 响应头顺序很重要**：`send_header()` 只是往缓冲区追加，必须在 `send_response()` 之后调用，否则 Cache-Control 会排在状态行前面，响应直接畸形（curl 报 "Received HTTP/0.9"）。
- **内容审查方法论**：逐字核查时，无法外部核实（web_search 不可用）的说法一律删掉或改成本地能证实的，别留"猜测性描述"。
- **`?ignorebrowser=true` 隐藏通道**：小黑屋引擎自带跳过手机检测的入口，可以给用户一个"继续用网页版"的退路。

## 踩坑记录

1. **`pgrep -f` 会匹配到自己命令行**：`pgrep -f "serve.py"` 会匹配到执行这条命令的 shell 自己，把自己杀了（第三次踩）。改用锚定 `^python3 serve\.py`，或 `ss -tlnp` 按端口找 PID。
2. **大改 HTML 用整体重写，别多处拼接**：五子棋重构时字符串手术翻车两次（正则吞闭合、文件内容重复），最后整体重写一次性解决。
3. **浏览器缓存坑**：服务器改了半天，用户说"没变化"——其实文件是新版，是浏览器缓存了旧页面。解法：服务器加 `Cache-Control: no-cache` 主动让浏览器重新验证；用户侧 Ctrl+F5 强制刷新。
4. **检查文本用 `includes()` 别用 `slice()`**：游戏页面 innerHTML 开头有一大堆 ASCII 排版空格，`slice(0,80)` 截出来全是空格，误报"游戏不渲染"。查内容用 includes 最靠谱。
5. **fontawesome 的 `../webfonts/` 路径**：all.min.css 引用相对路径 `../webfonts/`，所以字体文件要放在 `vendor/webfonts/`，不是 `vendor/fontawesome/webfonts/`。
6. **localStorage 旧值覆盖新默认**：改默认语言不够，老用户存档里的 `gameLanguage=en` 会覆盖新默认值，得加脚本强制改写旧值。
7. **headless Chromium 安装**：playwright 自带安装器卡死（CDN 被墙），手动 curl npmmirror 下载 zip 解压到 `~/.cache/ms-playwright/` 才装上。以后调试网页全靠它。
8. **改完文件一定要真浏览器验证**：静态检查发现不了图标裂、字体 404、加载卡死这类问题，装了 headless Chromium 后全部游戏真机回归了一遍。
