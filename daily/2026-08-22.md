## 学到的知识

### 免费建站三件套（eu.org + Cloudflare + Pages）

1. **eu.org 免费域名**：非营利组织提供的免费二级域名（`xxx.eu.org`），适合学生和个人项目。
   - 申请要填 NS（域名服务器）——填 Cloudflare 给你的两个 NS 地址。
   - ⚠️ **注册邮箱不能用 Gmail**：eu.org 明确警告收不到 Gmail 验证邮件，用 Outlook/163 等国内常用邮箱更稳。
   - 审核是人工的，要等几天到几周，期间 Cloudflare 站点是 Pending 状态，批准后自动变 Active。
2. **Cloudflare 免费托管**：Cloudflare Pages 可以免费托管静态网站，还能自动部署（连 GitHub 仓库 push 就更新），国内访问速度也不错。
3. **部署流程**：eu.org 批准 → Cloudflare 站点 Active → Pages 建项目 → 绑定自定义域名 → 完成。

### 开源游戏合规使用（重要！）

- 用别人的开源项目必须**保留 LICENSE 文件**，这是法律要求。
- **GPL 协议**的游戏（如五子棋、Candy Box 2）还必须在页面上**保留来源链接**。
- 小游戏本身不能改作者署名；但可以**追加自己的 CSS 覆盖样式**（不影响原功能，只换皮）。

### 其他小知识

- **ffmpeg 压图**：`q:v` 参数控制质量（2/3 为高质量），照片可以从几 MB 压到几百 KB，网页加载更快。
- **浏览器缓存坑**：改了 CSS/JS 后自己看没变化，是因为浏览器缓存了旧文件——按 **Ctrl+F5 强制刷新** 才能看到新效果。
- **毛玻璃卡片**：CSS 的 `backdrop-filter: blur()` 实现，深色背景下很有质感。
- **响应式布局**：`grid` 或 `flex` + 媒体查询，让两列画廊在手机上自动变一列。
