## 学到的知识

- **薄客户端 + 远程大脑架构**：卧室端只负责收音和放音（ESP32 + I2S 麦 + I2S 功放），所有智能都在服务器上——这样终端便宜（40 元内）、升级不用动硬件、还能复用树莓派的算力。
- **pip 源踩坑的通用解法**：`PIP_CONFIG_FILE=/dev/null` 可以临时绕过系统级 pip 配置（比如树莓派默认的 piwheels 源），排查 pip 卡死/403 时先想到它。
- **/tmp 是内存盘**：树莓派默认 /tmp 是 tmpfs（占内存），大文件下载/解压会撑爆内存——用 `TMPDIR` 指到磁盘路径。
- **配置文件的「实际生效」优先级**：xiaozhi 的 `data/.config.yaml` 覆盖根 config.yaml，且嵌套合并规则是「data 里没有的键回落到默认值」——改配置要显式写，注释掉等于失效。
- **WebSocket 鉴权头**：xiaozhi 服务器要求 Device-ID 头，不带会被直接断开——对接任何 ws 服务都要先看协议要求哪些 header。
- **工具调用（function calling）链路**：用户说「涿州今天天气怎么样」→ LLM 识别意图 → 调天气插件 → 结果回填 → 生成语音播报。免费无 key 的天气 API：Open-Meteo。
- **声纹识别管线**：说话 → ASR 转文字 → speaker embedding 模型提声纹向量 → 与注册样本比对打分 → 按说话人定制回应。sherpa-onnx 提供 SpeakerEmbeddingExtractor，模型要带元数据（add_meta_data.py 补丁）。
- **opus 帧时长**：服务器 opus 帧是 60ms = 960 样本，对接时解码必须精确按 960 样本，否则卡顿。
- **延迟链路优化思路**：预取（新连接先拉天气）、精确帧解码、抖动缓冲 + 时间轴排程播放——从 2.9s 砍到 1.3s。
- **DeepSeek 思考模式被官方禁用**：THINKING_DISABLED_DOMAINS 包含 deepseek.com，白嫖思考模式的思路不成立；要更快得换 GLM-4-Flash 之类。

## 踩坑记录

1. **piwheels 源卡死 pip**：`/etc/pip.conf` 默认指向 piwheels（树莓派专用源），装某些包会卡死 → `PIP_CONFIG_FILE=/dev/null` 绕过 + 阿里 PyPI 镜像（清华源 403）。
2. **pydub 在 Python 3.13 没 audioop**：audioop 模块被移除 → 本地补丁改 util.py 用 ffmpeg 替代。
3. **/tmp 内存盘爆满**：依赖下载解压把内存盘塞满 → TMPDIR 指到磁盘。
4. **mcp 版本必须钉死 1.22.0**：新版本不兼容，装错直接报错。
5. **sherpa-onnx 音频数据格式坑（大坑）**：`audio.samples` 是 [-1,1] 浮点列表，转 int16 必须 `*32767`，直接 `astype(int16)` 会全变 0 = 静音（Matcha 静音排查了半天）。
6. **Matcha TTS 配置三件套**：必须带 rule_fsts（phone.fst/date.fst/number.fst）+ vocos 声码器；vocos 从 vocoder-models release 下，走 gh.ddlc.top 代理（本机 GitHub 直连超时）。
7. **TTS 模型实测（Pi 5 性能榜）**：matcha-zh-baker 3.8 倍速但机器味；vits-zh-ll ~1:1 太慢；vits-zh-hf-fanchen-C 0.8 倍速；kokoro-int8 0.4 倍速；vits-icefall-zh-aishell3 9.2 倍速但输出 8kHz 闷。结论：本地免费 TTS 要么慢要么难听，云 API（CosyVoice2）最自然。
8. **xiaozhi 的 identify 用 Authorization: Bearer 头传 key**（不是 query 参数）——文档和实现不一致时以实测为准，服务端两种都要兼容。
9. **声纹模型不补丁就 segfault**：cnceleb_resnet34.onnx 需用 sherpa-onnx 官方 add_meta_data.py 打元数据（`--language Chinese`）才能被加载。
10. **记忆模块静默用错 LLM**：mem_local_short 必须显式写 `llm: DeepSeekLLM`，否则静默用无 key 的 ChatGLMLLM 报错。
11. **模板自带迷惑配置**：config.yaml 里自带一个指向 127.0.0.1:8880 的 CustomTTS 示例块，改配置时别被它带偏。
12. **fish.audio 国内打不开**：声音克隆（Fish Speech）方案搁置，api.fish.audio 也不通——选云服务前先测国内可达性。
