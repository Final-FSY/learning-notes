## 🧠 学到的知识

### 1. 唤醒词系统（ESP32 固件）
- 固件里有两套唤醒词机制：**EspWakeWord**（WakeNet 预设模型，如"你好小智"）和 **CustomWakeWord**（MultiNet 多命令词，**只有 ESP32-S3 支持**）
- 自定义唤醒词 = assets 分区里的 index.json + multinet 模型，**不用重新编译固件**！但注意：OTA 只更新 firmware，**不更新 assets**，所以 assets.bin 要网页刷机时一起刷
- 中文自定义唤醒词用拼音输入，小写带空格，如 "fan xiao jian"

### 2. GitHub Pages 的 Jekyll 坑
- GitHub Pages 默认用 Jekyll 构建，会**忽略所有 `_` 开头的文件**（模型文件 `_MODEL_INFO_` 直接 404）
- 解决：网站根目录加一个空 `.nojekyll` 文件，对纯静态页面无任何副作用

### 3. 填充音（思考语气词）设计的完整演进
这是今天最值钱的一课，踩了无数坑总结出来的：
- **单字"嗯"的问题**：TTS 合成单字语气词都短促（有声核心只有 0.3s），听起来像"肯定"而不是"思考"
- **句子型填充词的问题**：像"让我想想""稍等一下"这类带语义的话，会和 LLM 正片开头冲突（"让我想想"后面接"当然可以"很怪）；"稍等一下哦"还像服务员，不符合人设
- **思考感的物理本质**：音调**下行** + 拖长 + 音量渐弱。用自相关法测 f0 轨迹验证：下行 40-70Hz 才是真思考感
- **终极方案：让正片音色本人说英文语气词**（Hmm/Umm/Mmm）。原因：① 同音色零违和 ② 英文语气词是"非字哼鸣"，TTS 反而合成得自然（中文"嗯"是念字，永远不像）
- **toolkit**：edge_tts 的 Communicate 支持 rate/pitch 参数调语气（SSML 的 prosody 会被 edge_tts 解析坏，别用）

### 4. IPv6 导致 python 网络卡死的世纪大坑 🔴
- **现象**：curl 调 API 秒回，但 python（urllib/httpx/openai SDK）全部卡死 15 秒+
- **定位**：strace 发现 python 连完 IPv4 又去连 IPv6，挂在 EINPROGRESS——家庭宽带有 IPv6 地址但出站不通
- **原理**：python 的 Happy Eyeballs 算法会等 IPv6 超时才回落 IPv4，而 IPv6 超时很慢
- **治本修复**：`/etc/gai.conf` 加 `precedence ::ffff:0:0/96 100`（IPv4 优先）+ `/etc/hosts` 固定关键域名 IP
- **经验**：以后遇到 python 网络卡顿，第一个怀疑这个！

### 5. 免费 LLM 也要实测速度
- 名字带 flash 不代表快：glm-4-flash 首字 392ms，glm-4.5-flash 首字 20.7 秒（带思考、疑似限流）
- **带思考（reasoning_content）的模型不适合语音对话**——首字要等思考完，体验极差
- 实测方法论：httpx 流式测首字延迟（TTFT）+ 生成速度 + 工具调用决策时间
- 免费模型默认低温度/高确定性，讲笑话会重复 → 手动配 `temperature: 1.0, top_p: 0.95` + 人设提示词防重复

### 6. 远程排障方法论（GPT-SoVITS 修复）
- **拷目录会丢东西**：venv 里只有 pip/setuptools、项目大目录（模型权重）整个没了 → 用 robocopy `/MIR` 镜像同步解决
- **排查报错别瞎猜**：先给 except 加 `traceback.print_exc()` 让错误现形；多个实例并发加载大模型（5GB+ 内存）会互相干扰，测试前必须杀干净旧进程
- 接口参数名会随版本变化（`ref_audio_path` vs 旧的 `refer_wav_path`），升级后要核对

### 7. 其它零碎
- Open-Meteo API 的布尔参数要传字符串 `"true"` 而不是 True，否则报 Invalid variable type
- numpy 数组不能直接 `if pcm:`（ambiguous），要 `if pcm is not None and len(pcm)`
- aiohttp 服务端要配 aiohttp 客户端测试（websockets 库连不上）
- 树莓派生成 PDF：装 fonts-noto-cjk 中文字体 + playwright 的 chromium headless `--print-to-pdf`，中文完美
- 视觉模型可以评价照片：地平线别老居中、近处杂物要取舍
