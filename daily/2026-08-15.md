# 2026-08-15 · 第二天：Orange Pi 变身全屋广告拦截服务器 🦐

今天的主角是一台 **Orange Pi Zero 3**（1.5GB 内存的 ARM 小板子）。之前它跑 DietPi 带图形界面卡得要命，今天把它重刷成 **Armbian 精简版**，一路部署成了全屋的「DNS 广告拦截中心」。

## 📌 今天干了什么

1. **刷系统 + 首次配置**
   - 用 balenaEtcher 把 Armbian 25.5.1（Ubuntu 24.04 精简无桌面版）写进 32GB SD 卡。
   - 首次开机自动扩展分区（32GB 卡完整可用）、生成 SSH 密钥。
   - Armbian 首次登录流程：默认账号 root，登录后**强制改密码**，然后问要不要建普通用户（建议建一个，日常用普通用户更安全）。

2. **换国内软件源（apt 提速 700 倍）**
   - 默认源在国外，下载 6KB/s。换成阿里云镜像后 4.2MB/s。
   - **大坑：** Ubuntu 的 ARM 架构软件不在主仓库 `ubuntu/`，而在单独的 **`ubuntu-ports/`** 仓库！路径写错就是一片 404。

3. **升级系统 + 装基础工具**
   - `apt upgrade` 升级 131 个包。
   - 装了 curl、git、htop、vim 四个基础工具。

4. **配置 Tailscale（加密虚拟内网）**
   - 和树莓派、iPad 组进同一个虚拟内网，Orange Pi 拿到固定虚拟 IP，以后在外面也能访问它。

5. **安装 Docker + 部署两个服务**
   - Docker 29.7 + Compose 装好，镜像加速器配好（国内拉镜像必需）。
   - **AdGuard Home**（主菜）：全屋 DNS 广告拦截。
   - **Syncthing**（副菜）：照片/文件自动同步备份。

6. **逆向小米路由器 API（高光时刻 😎）**
   - 路由器网页界面找不到「静态 IP 绑定」入口？直接破解它的后台接口：
     - 从网页源码里翻出登录加密算法（SHA256 + 时间戳随机数），用 Python 模拟登录拿到管理令牌。
     - 找到绑定接口 `mac_bind`，一行调用把 Orange Pi 的 MAC 和 IP 绑定，**固定 IP 完成**。
     - 再找到 DHCP 设置接口 `set_lan_dhcp`，把全屋设备的 DNS 指向 AdGuard Home。
   - 原理：网页界面 = 「点菜菜单」，后台接口 = 「后厨」。绕过菜单直接进后厨下单，反而更快更精准。

## 🎓 今天学到的知识

- **`~` 家目录**：`~` = 当前用户的家目录。root 的家是 `/root`，普通用户 fsy 的家是 `/home/fsy`。用 `cd ~/xxx` 时先确认自己在哪个用户下。
- **dpkg 配置文件冲突**：升级时提示「配置文件被本地修改过，用哪个版本」→ 一律选 **keep the local version**（保留本地版），除非明确知道新版改了什么。选错可能把 SSH 搞挂。
- **内核模块与重启**：Armbian 升级内核后会清理旧内核的模块目录。**运行中的旧内核会「裸奔」**（缺模块），导致 Docker 这类依赖内核模块的服务起不来。解法：升级完重启，换上新内核。
- **判断报错等级**：`E:` 开头的才是致命错误；`W:` / `warning` 一般无害，可以忽略。
- **53 端口之争**：DNS 服务必须监听 53 端口，但 Ubuntu 自带的 systemd-resolved 也占着它。部署 AdGuard Home 前要先停用 systemd-resolved 并释放 53。
- **DHCP 租约机制**：路由器下发的配置（DNS）不是立即生效的，设备会「租」一段时间（我家是 12 小时）。改完路由器设置后，设备要等租约续期或重连 WiFi 才拿到新配置。
- **cmd 粘贴长命令会丢字符**：Windows 的 cmd 粘贴大段命令偶尔会「吃掉」一两个字符，命令会莫名其妙报错。遇到这种情况把命令拆短一点重试。

## 🕳️ 踩坑记录

| 坑 | 解法 |
|----|------|
| 阿里云 Ubuntu 源全 404 | ARM 架构要用 `ubuntu-ports` 路径，不是 `ubuntu` |
| Docker 启动失败（iptables 模块找不到） | 旧内核模块被清，重启换新内核 |
| AdGuard 装不上（53 端口被占） | 停用 systemd-resolved，释放 53 |
| 全家短暂断网 | 改路由器 DHCP 会触发设备集体重连（1-3 分钟恢复），不是故障 |
| gpg 密钥导入报错 | 网页下载的密钥是文本格式，要 `gpg --dearmor` 转二进制 |
| SSH 看不到密码输入 | 正常现象，不是键盘坏了 |
