## 学到的知识

- **Theos 是什么**：一套在 Linux/macOS 上交叉编译 iOS 越狱插件的工具链，用 make 管理构建，产物可以是 .deb（Cydia/Sileo 装）或 .ipa（TrollStore 装）
- **ldid 是什么**：越狱圈的"假签名"工具，代替 Apple 的 codesign 给二进制签名，让 iOS 设备在越狱环境下直接跑未签名 App
- **SDK 精简版概念**：开发用的 iOS SDK 可以只带头文件和 tbd（文本格式的库描述文件），不需要完整的 1GB 系统镜像——编译链接够用就行
- **Open-Meteo 是免费天气 API**：不用注册 key 就能用，对个人项目很友好
- **零依赖 Python 服务**：只用标准库（urllib、xml.etree）写 HTTP 服务 + RSS 解析，部署时不用装任何 pip 包，拷过去就能跑
- **IPA 可以很小**：一个功能完整的信息屏 App 才 39K，因为没打包系统镜像

## 踩坑记录

1. **GitHub release-assets 直连间歇性超时**，ghfast/gh-proxy/moeyy 等代理全挂，最后 **gh.ddlc.top 可用**（curl 稳，wget 容易超时）。下载脚本用 `curl -C -`（断点续传）+ `--max-time 90` 循环重试
2. **pkill -f 模式会匹配到自己的命令行**：`pkill -f xxx` 会杀掉包含该模式的 bash -c 进程本身，导致"自杀"。要分开写，或用更精确的模式
3. **Theos 在 Linux 上必须装交叉编译 toolchain**（iOSToolChain），不装的话 clang 路径不存在，编译直接失败
4. **图标要生成到项目 Resources/ 目录**：make stage 会从那里重新复制，如果生成到 .theos 产物目录会被覆盖掉
5. **SDK 下载"卡住"是错觉**：其实是 16MB 早就下完了，Theos 的 SDK 包就是这么小
